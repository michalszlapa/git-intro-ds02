# Git w praktyce: zajęcia DS02-05-26

Repo startowe do zajęć o gicie. Każdy student tworzy **własną kopię** tego repo i pracuje w niej.

## Jak zacząć
1. Na GitHubie kliknij **Use this template** → **Create a new repository**. Nazwij je `git-intro-ds02-<twoj-login>`.
2. Sklonuj swoją kopię: `git clone https://github.com/<twoj-login>/git-intro-ds02-<twoj-login>.git`
3. Wejdź do katalogu i sprawdź: `git status`

## Co jest w repo
- `zadania/` — krótkie zadania krok po kroku (01–05)
- `konflikt/` — plik do ćwiczenia rozwiązywania konfliktów
- `.gitignore` — pliki, których git nie powinien śledzić
- `ściągawka.md` — najczęstsze komendy i wyjście z typowych problemów

## Na koniec zajęć
W swoim repo powinieneś mieć:
- historię commitów z sensownymi komunikatami,
- gałąź, która została scalona do `main`,
- rozwiązany konflikt,
- otwarty Pull Request w swoim repo, który ktoś z grupy skomentował.

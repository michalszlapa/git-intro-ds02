# Zadanie 5: zdalne repo i Pull Request

1. Wypchnij `main` do GitHuba: `git push`
2. Utwórz gałąź `moja-praca`, zrób w niej zmianę w `notatki.md`, zrób commit.
3. Wypchnij ją: `git push -u origin moja-praca`
4. Na GitHubie otwórz **Pull Request** z `moja-praca` do `main`.
5. Napisz w opisie PR, co zmieniłeś/aś i dlaczego.
6. Poproś kolegę/koleżankę o komentarz. Sam/a zrób przegląd ich PR.

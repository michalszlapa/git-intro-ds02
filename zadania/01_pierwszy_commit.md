# Zadanie 1: pierwszy commit

1. Sprawdź stan: `git status`
2. Dopisz linię do `notatki.md`.
3. Sprawdź różnicę: `git diff`
4. Dodaj plik do poczekalni: `git add notatki.md`
5. Zrób commit: `git commit -m "Dodaj pierwszą notatkę"`
6. Zobacz historię: `git log --oneline`

**Pytanie:** czym różni się `git diff` od `git diff --staged`?
